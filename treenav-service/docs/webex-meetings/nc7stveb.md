# Adjust how many participants appear in grid view in meetings and webinars

- [Desktop, Web](#Cisco%5FTask%5Fin%5FList%5FGUI.dita%5F755128cc-fccc-433f-a8f7-aaa10822d8d3)
- [iOS](#Cisco%5FTask%5Fin%5FList%5FGUI.dita%5F463e2425-4064-40d8-b990-3661269cf84e)
- [Android](#Cisco%5FTask%5Fin%5FList%5FGUI.dita%5Fc0870efb-5005-4075-bcda-f097cc03a3e6)

Grid view automatically adjusts to the number of participants that attend your meeting. By increasing or decreasing the number of participants that appear, you set the maximum number that can appear per page. When fully zoomed out, up to 81 participants can appear on-screen together for the desktop app, and up to six for the web app. When fully zoomed in, only one participant per page appears for the desktop and web app. Zooming in or out also increases or decreases the size of the videos in grid view.

| Use the slider ![Increase or decrease the number of people in Grid view icon](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/450001-460000/457001-458000/457855.jpg) to increase or decrease the number of people that appear. Set the default maximum number of grid view videos for the desktop app by going to Show Menu Bar \>  Meeting \>  Meeting Settings \>  Layout. |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

Set the layout of [grid view for portrait and landscape mode](https://help.webex.com/nhuie12/). On iPhones, you can set a 1×2 or 2×2 grid layout in portrait mode and a 2×2 or 3×2, or 3×3 grid layout in landscape mode. On iPad, you can set a 2×3, 2×4, or 3×7 view in portrait mode, and a 3×2, 3×3, or 5×5 grid layout in landscape mode.

| 1 | Go to Settings \> Audio & Video and then scroll down to Portrait Video Layout and Landscape Video Layout.                                                                                                                                                                                                                                                                                                                                       |
| - | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2 | Select the layout that you want to use for portrait and landscape modes. iPhone ![Portrait and Landscape Grid view layouts](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/440001-450000/449001-450000/449149.jpg) iPad ![changing your video layout options from the settings menu on iPad](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/450001-460000/450001-451000/450161.jpg) |

You can set the layout of [grid view in both portrait and landscape mode](https://help.webex.com/nhuie12/). On Android phones, you can set a 1×2 or 2×2 grid layout in portrait mode and a 2×2 or 3×2 grid layout in landscape mode. On Android tablets, you can set a 2×3, 2×4, or 3×7 view in portrait mode, and a 3×2, 3×3, or 5×5 grid layout in landscape mode.

| 1 | Go to Settings \> Audio & video, and then scroll down to Grid View Layout.                                                                                                                                                                                                                                                                                                                      |
