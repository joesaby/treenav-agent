# Deactivate a user from your organization

An administrator can deactivate a user using Control Hub. This is different to deleting a user because the user remains in your user list, so that you can reactivate them if needed. If your organization uses directory synchronization (e.g. DirSync, Okta, Entra ID), then you should manage users in your directory instead, and then sync any changes to Webex.

| 1 | Sign in to [Control Hub](https://admin.webex.com/).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| - | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2 | Go to Management \> Users. Select the user you want to deactivate.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| 3 | Click the more ![More Options button](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/430001-440000/436001-437000/436677.jpg) option.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| 4 | Click Deactivate User. Webex services, including Webex Calling services, are now deactivated for this user. When deactivated, Webex App users will be signed out from their sessions. When people call the deactivated user’s number, they will hear this message: _The person you are trying to reach is out of service._ All user access to the user portal and Control Hub is disallowed. MPP phones continue to support calling for outbound and inbound calls for a short time, unless the administrator enables call intercept for that user. For more information about call intercept, see [Configure Call Intercept](https://help.webex.com/article/n8rhdrd/Configure-call-intercept-in-Control-Hub). To reactivate a deactivated user, click More Actions \> Reactivate.Users are automatically deleted when they have been deactivated for 30 days. |
