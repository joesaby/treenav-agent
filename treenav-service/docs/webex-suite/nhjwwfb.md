# Languages supported by Cisco AI Assistant

## AI Assistant for Webex Suite

AI Assistant offers a range of capabilities that can help automate some of your day-to-day tasks, such as summarizing messages and conversations, translations, in-meeting summaries, as well as meeting and call recording summaries and transcripts. 

To learn more about AI Assistant for Webex Suite, see [webex.ai](https://www.webex.ai/).

For language support for Webex services and applications without AI Assistant, see [Languages Webex supports](https://help.webex.com/en-us/article/934ty8/).

## AI for message translation

Messages in a space can be translated into 120+ languages, using the language selection option in Webex App. See [Translate messages in a space](https://help.webex.com/en-us/38383eb/).

This is independent of the [Real Time Translation license](https://help.webex.com/article/ncd9ukq/).

## AI Assistant supported language overview for meetings

[Real-time Translation](https://help.webex.com/article/nqzpeei/) is an add-on for Webex Meetings and Webex Webinars, which allows you to have more inclusive and engaging meetings and webinars. The following table provides a brief overview of the languages supported for use with AI Assistant features, both with and without a Real-time Translation licence.

|                                                     | Language feature                | With Real Time Translation Licence                                                      | Without Real Time Translation License    |
| --------------------------------------------------- | ------------------------------- | --------------------------------------------------------------------------------------- | ---------------------------------------- |
| **AI Assistant meeting summaries and action items** | **In-meeting: Spoken language** | 16 languages​ \*(Not dependant on the Real Time Translation license for Paid customers) | 5 Languages available for free customers |
| **In-meeting: ask me anything**                     | 29 Languages                    | 29 Languages                                                                            |                                          |
| **Post-meeting: Translation language**              | 137 Languages                   | 137 Languages                                                                           |                                          |

## AI-generated in-meeting summaries

[AI Assistant for in-meeting summaries](https://help.webex.com/article/nyzkuik/) supports 29 languages. By default Webex App uses the [language settings](https://help.webex.com/en-us/n739fbo/) that you selected on your device, or browser. AI Assistant then provides the in-meeting summary, and responds to your questions in that language, based on your app settings.

This is independent of the [Real Time Translation license](https://help.webex.com/article/ncd9ukq/).

## AI-generated recording summaries and transcripts

Currently, [AI generated summaries and transcripts in recordings](https://help.webex.com/en-us/nslyqzx/) are generated in the spoken language set for the meeting, with only one supported language for translation. 

### Supported translation languages

- English

## AI for Devices

When enabled by your organization administrator, AI Assistant lets you enable in-meeting summaries on your device, to catch up quickly if you're running late, and find out what the action items are. You can also translate the transcript and summary into your preferred language during the meeting.

See [Cisco AI Assistant in Board, Desk, and Room Series on devices](https://help.webex.com/e4roeg/).

## AI for Calling

 When enabled by your organization administrator, AI can generate a call recording summary, which lists the action items, and also provides the full transcript from the call. During a call AI can also help generate closed captions to help you follow conversations more easily, and stay engaged.

## AI generated summaries for call recordings

 When enabled by your organization administrator, AI can generate a call recording summary, which lists the action items, and also provides the full transcript from the call.

see [AI-generated summaries for call recordings](https://help.webex.com/article/9leme/).

### Supported languages for call recordings

- Currently only available in English.
