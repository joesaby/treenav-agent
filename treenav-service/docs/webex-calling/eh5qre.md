# Configure Do Not Disturb (DND) override for Webex Go calls

You'll see these options in Webex mobile app or User Hub if your administrator has set you up with Webex Go.

- [Mobile](#task-template%5F657a37d2-5852-4c19-b0b4-f63cfb95d48b)
- [User Hub](#task-template%5F0e2273de-4c84-4c4f-9578-e09c27fcfba0)

| 1 | Open Webex App and sign in.                                                                                                                         |
| - | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2 | Tap your Profile picture.                                                                                                                           |
| 3 | Tap Settings \> Notifications \> Calling.                                                                                                           |
| 4 | By default, the Always alert Webex Go device option is turned on, so the device rings for all calls. To stop receiving alerts, turn off the option. |

| 1 | Sign in to [User Hub](https://user.webex.com/webappng/hub/welcome).                                                                                                                                                                          |
| - | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2 | Choose Settings from the left navigation bar.                                                                                                                                                                                                |
| 3 | Click the Calling tab.                                                                                                                                                                                                                       |
| 4 | On the Call Settings tab, the DND Override for Webex Go mobile devices option is turned on by default, allowing calls during Do Not Disturb (DND), Quiet Hours, or while presenting. To block calls during these times, turn off the option. |
