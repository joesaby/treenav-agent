# Configure custom connector for Webex Contact Center

Custom connector is required only if you need to authenticate the endpoint. You can disable the Use Authenticated Endpoint toggle button when you configure the HTTP Request activity in the Flow Designer.

You can add up to ten custom connectors for your organization.

| 1 | Log in to your customer organization at <https://admin.webex.com> and navigate to Services \> Contact Center \> Tenant Settings \> Integrations \> Connectors.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| - | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 2 | On the Custom Connector card, click Set Up or Add More.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| 3 | In the Name field, enter a unique name for the connector (for example, Contact Center Connector).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| 4 | Choose the type of authentication from the Authentication Type drop-down list: Basic Authentication (default) OAuth 2.0                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| 5 | In the Resource Domain URL field, enter the URL of a domain name with an https:// prefix.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| 6 | If the Authentication Type is OAuth 2.0, choose one of the following grant types from the Grant Type drop-down list: Client credentials - certificate Client credentials - client secret Password Grant The Webex Contact Center credential service (part of the Control Hub connector) internally ensures that the OAuth access token remains valid. Flow developers need not be concerned about managing the access token after creating the connector. If you choose Client credentials - certificate, enter the following details: In the Public key (certificate) field, enter the public key certificate. Public key corresponds to the certificate.pem file. In the Private key (certificate)field, enter the private key certificate. Private key corresponds to the key.pem file generated. This corresponds to the certificate that is generated (either self signed or CA signed) and uploaded on the application. If you choose Client credentials - client secret, enter the following details: In the Client ID field, enter the service client ID. In the Client Secret field, enter the client secret. If you choose Password grant, enter the following details: In the Username field, enter the username of the service account. In the Password field, enter the password of the service account. In the Client ID field, enter the service client ID. In the Client Secret field, enter the client secret. In the Token URL field, enter the token URL of the authorization server. In the Scope field, enter the scope for the client credentials grant. |
| 7 | If the Authentication Type is Basic Authentication and the Grant Type is Password Grant, In the Username field, enter the username of the service account. In the Password field, enter the password of the service account. In the Validation URL field, enter the URL to validate the username and password.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| 8 | Click Done to save the connector details and click Close.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |

The following HTTP connectors are available:
- [Zendesk IVR Custom HTTP Connector](https://github.com/CiscoDevNet/webex-contact-center-crm-integrations/tree/main/Zendesk/zendesk-ivr-http-connector)
- [ServiceNow IVR Custom HTTP Connector](https://github.com/CiscoDevNet/webex-contact-center-crm-integrations/tree/main/ServiceNow/servicenow-ivr-http-connector)
- [Microsoft Dynamics IVR Custom HTTP Connector](https://help.webex.com/en-us/article/preview/gtf0rt/Create-public-and-private-key-certificates-for-Microsoft-Dynamics-365-Connector)

What to do next

After you successfully save the connector, you can use it in Flow Designer.
- For more information on Flow Designer, see the [_HTTP Request Settings_](https://www.cisco.com/c/en/us/td/docs/voice%5Fip%5Fcomm/cust%5Fcontact/contact%5Fcenter/webexcc/SetupandAdministrationGuide%5F2/b%5Fmp-release-2/b%5Fcc-release-2%5Fchapter%5F0100.html#Cisco%5FGeneric%5FTopic.dita%5Fb1192550-38d4-46e5-be3d-2119794def93%5F%5Fsection%5Fwlt%5Flj1%5Fkrb)section in the _Working with Flow Designer_ chapter of [_Cisco Webex Contact Center Setup and Administration Guide_](https://www.cisco.com/c/en/us/support/customer-collaboration/webex-contact-center/series.html).
