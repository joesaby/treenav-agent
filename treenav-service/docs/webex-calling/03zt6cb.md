# Set up simultaneous ring for users and workspaces

Before you begin

To set up this feature for workspaces, ensure that workspaces have a professional license assigned. To find out more about the features that are available with workspace licenses, see [Features available by license type for Webex Calling](https://help.webex.com/n1qbbp7).

| 1  | Sign in to [Control Hub](https://admin.webex.com/).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| -- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2  | Go to the respective path. For Users: Go to Management \> Users. Then, select a user. For Workspaces: Go to Management \> Workspaces. Then, select a workspace.                                                                                                                                                                                                                                                                                                                                                                                             |
| 3  | Click the Calling tab.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| 4  | Go to the Call handling section and select Simultaneous Ring.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| 5  | Turn on the toggle, and enter the phone number in the Set number field. Click Add personal number to continue adding the number. You can enter up to 10 phone numbers to ring simultaneously.                                                                                                                                                                                                                                                                                                                                                               |
| 6  | Check the Do not ring when on a call check box if you don't want the entered phone numbers to ring when a user is on a call.                                                                                                                                                                                                                                                                                                                                                                                                                                |
| 7  | Check the Answer Confirmation check box if you want to prompt the call recipient to press a key before being connected.                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| 8  | Toggle on Apply Schedules If you want to set up when these phone numbers ring.                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| 9  | Select a predefined schedule from the drop-down menu. If you don’t see a schedule that you want to use for this setting, you can create a new schedule from the Schedules page. For more information, see [Create Schedules](https://help.webex.com/nbelebf/).                                                                                                                                                                                                                                                                                              |
| 10 | Click Add Schedule to set the following parameters: Schedule—Select the predefined schedule for when the calls to ring simultaneously from the drop-down list. If you're a location administrator, only the schedules pertaining to your assigned locations appear. Calls from—Select to apply the simultaneous ring for calls from Any Phone Number or Select Phone Numbers. If you choose Select Phone Numbers, enter the additional details. Ring or Don't ring—Choose whether to apply the simultaneous ring to calls that fit within these parameters. |
| 11 | Click Save. The schedule is added to a Ring or Don't Ring table. You can edit or delete schedules from the tables, as needed. Don't Ring takes precedence over Ring.                                                                                                                                                                                                                                                                                                                                                                                        |
| 12 | Click Save. A user can also set up the simultaneous ring on their own in the user portal. For more details, see [Configure simultaneous ring](https://help.webex.com/x4ifwt). Any changes made to these settings by the user will be reflected in both the user portal and Control Hub.                                                                                                                                                                                                                                                                     |
