# Supported attachment types for digital channels in Webex Contact Center

- [Livechat](#generic-template%5F86caebad-4e98-46ad-9e6d-a01b8561cfdf)
- [WhatsApp](#generic-template%5Fea3e3702-08fd-4f8c-b31c-e68ae840aebc)
- [Facebook Messenger](#generic-template%5Fbeb0e8d6-1531-42cd-9d93-c68770317f15)
- [Email](#generic-template%5F591cd98f-d5a4-4a12-bca4-b44c6c882151)
- [Apple Messages for Business (AMB)](#generic-template%5Fce232185-7c48-4b91-8e1f-6dac63f29c77)

The following file types are supported in Livechat digital channel for regular attachments.

__Table 1\. Supported attachment file types in Livechat__
| Communication     | File Types                                              |
| ----------------- | ------------------------------------------------------- |
| Agent to Customer | .doc, .docx, .pdf, .pptx, .ppt, .xls, .xslx, .csv, .txt |
| Customer to Agent | .doc, .docx, .pdf, .pptx, .ppt, .xls, .xslx, .csv       |

The following file types are supported in WhatsApp digital channel for regular attachments.

__Table 2\. Supported attachment file types in WhatsApp__
| Communication     | File Types                                                                             |
| ----------------- | -------------------------------------------------------------------------------------- |
| Agent to Customer | .doc, .docx, .pdf, .pptx, .ppt, .xls, .xslx, .txt                                      |
| Customer to Agent | .doc, .docx, .pdf, .pptx, .ppt, .html, .xls, .xslx, .rtf, .xml, .msg, .eml, .csv, .txt |

The following file types are supported in Facebook Messenger digital channel for regular attachments.

__Table 3\. Supported attachment file types in Facebook Messenger__
| Communication     | File Types                                                                             |
| ----------------- | -------------------------------------------------------------------------------------- |
| Agent to Customer | .doc, .docx, .pdf, .pptx, .ppt, .xls, .xslx, .txt                                      |
| Customer to Agent | .doc, .docx, .pdf, .pptx, .ppt, .html, .xls, .xslx, .rtf, .xml, .msg, .eml, .csv, .txt |

The following file types are supported in Email digital channel for regular attachments.

__Table 4\. Supported attachment file types in Email__
| Communication     | File Types                                                                                                                                                                                                                                             |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Agent to Customer | .doc, .docx, .pdf, .pptx, .ppt, .xls, .xslx, .txt                                                                                                                                                                                                      |
| Customer to Agent | .doc, .docx, .pdf, .pptx, .ppt, .html, .xls, .xslx, .rtf, .xml, .msg, .eml, .csv, .txtIncoming emails with .msg and .eml attachments sent from Microsoft Outlook might be received without the attachments due to a limitation from Microsoft Outlook. |

The following file types are supported in Apple Messages for Business (AMB) digital channel for regular attachments.

__Table 5\. Supported attachment file types in AMB__
| Communication     | File Types                                                                                                                                                                                                                                                                          |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Agent to Customer | .jpg, .jpeg, .gif, .png, .mp4, .mp3, .pdf, .docx, .doc, .txt, .xls,.xlsx, .csv, .ppt, .pptx, .wav, .ogg, .mpeg                                                                                                                                                                      |
| Customer to Agent | .doc, .docx, .pdf, .pptx, .ppt, .html, .xls, .xslx, .rtf, .xml, .msg, .eml, .csv, .txtApart from the file types listed above, AMB channel also supports various other file formats listed [here](https://register.apple.com/resources/messages/msp-rest-api/type-text#attachments). |
