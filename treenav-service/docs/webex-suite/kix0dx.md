# Add verified domains to use for partner UPN in Partner Hub

## Add a verified domain to use for partner UPN

When you add a verified domain to use for partner UPN, you can provision customers and their users with licenses even though those users don't have access to an email inbox with that domain.

Before you begin

You must have [verified a domain in your organization](https://help.webex.com/cd6d84#Cisco%5FTask.dita%5F01123578-ddcb-41d5-9bce-df3af6045e8b) first before you can add a domain to use for partner UPN.

| 1 | Sign in to [Partner Hub](https://admin.webex.com).                                      |
| - | --------------------------------------------------------------------------------------- |
| 2 | Click Sign in to my organization.                                                       |
| 3 | Go to Organization Settings \>  Domains.                                                |
| 4 | Click on More options next to the verified domain that you want to use for partner UPN. |
| 5 | Select Add domain for partner UPN use.                                                  |

## Remove a verified domain from use for partner UPN

You can remove a verified domain from being used for partner UPN if you don't need that domain anymore.

Existing customers and their users can still sign in to Webex with the removed domain.

| 1 | Sign in to [Partner Hub](https://admin.webex.com).                                      |
| - | --------------------------------------------------------------------------------------- |
| 2 | Click Sign in to my organization.                                                       |
| 3 | Go to Organization Settings \>  Domains.                                                |
| 4 | Click on More options next to the verified domain that you want to use for partner UPN. |
| 5 | Select Remove domain for partner UPN use.                                               |

## Initiate a one-time password for a partner UPN user

If a customer account uses a user principal name (UPN) rather than an email address, you can generate a one-time password for them. You can then send this password to the customer in an email or read it to them over the phone, allowing them to sign in for the first time.

Before you begin

Make sure you've verified the customer domain.

| 1 | Sign in to [Partner Hub](https://admin.webex.com).                                         |
| - | ------------------------------------------------------------------------------------------ |
| 2 | Click Sign in to my organization.                                                          |
| 3 | Go to Users and select the user whose password you want to generate.                       |
| 4 | Click Actions \> Generate a one time password. One-time passwords expire after seven days. |
