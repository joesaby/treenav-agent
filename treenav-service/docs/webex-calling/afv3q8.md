# Control Hub user management CSV file reference

Use the following table as a reference for CSV file fields when you're [modifying users in Control Hub](https://help.webex.com/e2okky/). If you want to change user attributes in a specific Webex Meetings site, refer to [Webex Meetings CSV file import and export in Control Hub](https://help.webex.com/nh17y2u/).

If you use Directory Connector to synchronize users, leave any [overlapping attributes](https://help.webex.com/zqvufbb/Deployment-Guide-for-Directory-Connector#concept%5FD3633C93EF8CEFFE16A995F18BA8CFD7) in the CSV file blank before you upload it to Control Hub.

- Modifying any read-only fields can trigger errors when you upload the CSV file.
- Any [suspended services](https://help.webex.com/nctesy/) will appear as (Suspended) in the field name. Control Hub won't accept a CSV file with a suspended service marked TRUE.
- Export a new CSV to capture the latest information for the fields and avoid errors during the import of changes.
