# Webex AI Agent for Microsoft 365 Copilot

You'll need to add this feature from **Microsoft Marketplace** first, then your **Microsoft 365** administrator can enable it for you.

When Webex AI Agent is enabled, it can be accessed directly from within Copilot.

| 1 | Open the Copilot panel in Microsoft Teams, Word, or PowerPoint. You can access Webex AI Agent in two ways: Click Switch Copilot ![Menu icon](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/430001-440000/439001-440000/439808.jpg) in the header bar, then select Webex AI Agent from the list. Or, click Open ![Upload image icon](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/450001-460000/459001-460000/459162.jpg) in the **Copilot** chat interface, then select Webex AI Agent.                             |
| - | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2 | Go to the Webex AI Agent chat interface. Select from the suggested prompt options, or ask Webex AI Agentquestions to search for your Webex meeting content, such as meeting recording summaries, transcripts, and action items, based on topics, participants, or specific time frames. Webex AI Agent can only use meeting recordings that you have access to, as a knowledge source. You can use the log out prompt to disconnect your Webex account, and Webex AI Agent, from **Microsoft 365**. When your authorization expires, you must sign-in to your Webex account again. |
