# Schedule and join meetings with Webex Scheduler for Microsoft Outlook

[Add the Webex Scheduler add-in from Microsoft AppSource](#id%5F96499)

If you have a Microsoft 365 acccount and your administrator hasn’t installed the Webex Scheduler add-in, you can install the app yourself.

| 1 | Go to [Microsoft AppSource](https://appsource.microsoft.com/).                                                                                    |
| - | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2 | Search for the Webex Scheduler add-in.                                                                                                            |
| 3 | Select Get it now and follow the on-screen instructions. After you've added the app, follow the instructions in _Set your Webex site in Outlook_. |

[Set your Webex site in Outlook](#id%5F96378)

Before you can schedule a meeting using the Webex Scheduler, you must specify the Webex site to use with your account.

| 1 | If you're using Outlook for desktop, in the Cisco Webex group on the ribbon, select Add Webex Meeting. ![Add Webex Meeting](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/430001-440000/433001-434000/433731.jpg) If you're using Outlook on the web, select New event \> Cisco Webex Scheduler ![Webex Scheduler](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/430001-440000/433001-434000/433680.jpg) \> Add Webex Meeting. To see this option, you or your administrator must have added the Webex Scheduler add-in and your Webex site administrator must have configured the Webex Scheduler for Microsoft 365. The Welcome screen appears. ![Welcome screen of Webex scheduler](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/450001-460000/455001-456000/455004.jpg) |
| - | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2 | Select Get Started.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| 3 | Select or enter the Webex site URL that you want to use, in the format company, and then select Next. ![Enter the Webex site URL to configure Webex scheduler](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/450001-460000/455001-456000/455005.jpg) If you see a message that Webex Preferences wants to display in a new window, select Allow.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| 4 | The Sign in screen opens in a new browser window. Enter your Microsoft 365 email address, and then select Next. ![Enter your Microsoft 365 email address to configure Webex scheduler](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/430001-440000/433001-434000/433679.jpg)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| 5 | Enter your Microsoft 365 password, and then select Sign in. ![Enter your Microsoft 365 password to configure Webex scheduler](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/430001-440000/433001-434000/433681.jpg) If you see a _Stay signed in?_ message, select Yes to reduce the number of times you have to sign in.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |

[Schedule a meeting from Outlook](#id%5F96494)

After you've set your Webex site, you can add a Webex meeting to any appointment that you create in Outlook.

| 1 | Create an appointment in Outlook.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| - | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2 | Enter the appointment name, meetings classification level, location, and start and end times.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| 3 | If you want the appointment to repeat, do one of the following: In the desktop app, select Recurrence in the ribbon and then select how often you want this appointment to repeat and when you want it to end.In the web app, click the drop-down list in the Repeat field and select how often you want the meeting to repeat and when you want it to end.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| 4 | To invite others, do one of the following: In the desktop app, select Invite Attendees and then type one or more email addresses in the Required box.In the web app, type one or more email addresses in the Invite attendees field.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| 5 | If you're using Outlook for desktop, in the Cisco Webex group on the ribbon in Outlook, select Add Webex Meeting. ![Add Webex meeting](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/430001-440000/433001-434000/433731.jpg) If you're using Outlook on the web, select the Cisco Webex Scheduler ![Webex](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/430001-440000/433001-434000/433680.jpg) and from the drop-down list select Add Webex Meeting. ![Add Webex Meeting](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/450001-460000/455001-456000/455006.jpg) After a few moments, a link to the meeting is added to the location field and the meeting details are added to the body of the appointment. If you encounter an error after trying to add a meeting to Webex Meetings, you can see the error details above the body of the appointment.                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| 6 | (Optional) Edit the meeting options, such as add an alternate host or cohost. You can also set the entry and exit tone, change the meeting password, or add a tracking code. If you're using Outlook for desktop, in the Cisco Webex group on the ribbon in Outlook, select Webex Preferences. From Meetings classification level, select the drop-down menu to view available classification labels. These labels help ensure information is shared appropriately and aligns with your organization’s security standards. When you turn on classifications, the system automatically creates a public classification and set this as the default. You can rename the public classification, but can't delete it. As the meeting host, you can change the classification any time before the meeting starts, the classification can't be changed once the meeting has started, and when the meeting has ended. ![Add Webex Preferences to configure Webex scheduler](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/450001-460000/455001-456000/455007.jpg) If you're using Outlook on the web, select Cisco Webex Scheduler ![Webex](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/430001-440000/433001-434000/433680.jpg) \> Webex Preferences. Select Update meeting when you've finished editing the meeting options. |
| 7 | Select Send. The appointment shows the meeting details, including a link to join the meeting. You can copy the link and share it with others.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |

What to do next

Depending on your site settings, you may be able to [integrate your Microsoft 365 calendar with your Webex site](https://help.webex.com/m0trp7/). You'd be able to access Webex meetings that were scheduled in Microsoft 365 from Meetings.

[Start or join a meeting](#id%5F98266)

It's convenient to start or join a meeting that's been scheduled using the Webex Scheduler in Microsoft Outlook.

| To start or join a meeting, do one of the following: Select the link in the calendar invite in Outlook.Join from a video system or application by dialing the video address in the calendar invite.Join by phone by dialing the number in the calendar invite.![Start or join a meeting](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/420001-430000/429001-430000/429366.jpg)Select Join on your cloud-registered video device. The Join button appears 5 minutes before the meeting starts.![Join Webex Meeting](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/420001-430000/429001-430000/429395.jpg) |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

[Edit a meeting](#id%5F99408)

After you schedule a meeting, use Outlook to edit it at any time. Change the attendees and the meeting information, such as the date and time, or change the meeting options, like the meeting type or template.

When you edit a scheduled meeting, an updated email invitation gets sent to the attendees, and the meeting information on your Webex site gets updated.

| 1 | In your Outlook calendar, edit the scheduled meeting.                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| - | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2 | Change any of the following: To add attendees, select Required. Edit the subject, location, date, time, or recurrence. The Webex meeting details look similar to the following: ![Webex meeting details](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/450001-460000/455001-456000/455008.jpg)                                                                                                                                                                                              |
| 3 | Change the Webex meeting options. If you're using Outlook for desktop, in the Cisco Webex group on the ribbon in Outlook, select Webex Preferences.![Preferences](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/430001-440000/433001-434000/433731.jpg)If you're using Outlook on the web, select Cisco Webex Scheduler ![Cisco Webex Scheduler](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/430001-440000/433001-434000/433680.jpg) \> Webex Preferences. |
| 4 | Select Update when you've finished editing the meeting options, then select Send Update. If you're using Outlook for Microsoft Exchange, you don't need to select Update. Your meetings update automatically when you change meeting details.                                                                                                                                                                                                                                                                              |

[Remove a meeting](#%5F0837a096-7e3e-4b52-8d28-d65e34f2d161)

Remove Webex meetings from Outlook appointments that no longer need them, or if you want to change the Webex meeting type.

| 1 | In your Outlook calendar, open an appointment that contains a Webex meeting.                                                                                                                                                                                                                                                                                                                                                                                                                        |
| - | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2 | Open Webex Preferences: If you're using Outlook for desktop, in the Cisco Webex group on the ribbon in Outlook, select Webex Preferences.![Add Webex meeting](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/430001-440000/433001-434000/433731.jpg)If you're using Outlook for web, select Cisco Webex Scheduler ![Webex](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/430001-440000/433001-434000/433680.jpg) \> Webex Preferences. |
| 3 | Select Remove or Remove meeting.                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |

[Change the default meeting type](#id%5F96503)

You can change the default type of Webex meeting to use when you add a meeting to an appointment in Outlook:
- **Generate a one-time meeting link**—Each meeting has a unique meeting link and video address.
- **Use my Personal Room link**—All meetings use your Personal Room link as the meeting link and your Personal Room video address as the video address.

| 1 | If you're using Outlook for desktop, in the Cisco Webex group on the ribbon in Outlook, select Webex Preferences. ![Preferences](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/430001-440000/433001-434000/433731.jpg) If you're using Outlook on the web, select New event \> Cisco Webex Scheduler ![Webex](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/430001-440000/433001-434000/433680.jpg) \> Webex Preferences. |
| - | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2 | Select the default meeting type under Webex Meeting Link and select Save. The change applies to all future Webex meetings that you add to appointments.                                                                                                                                                                                                                                                                                                                                 |

[Change the Webex site you use in Outlook](#id%5F96806)

If there's more than one Webex site that you use for meetings, you can specify which site you prefer to use when you add a Webex meeting to an appointment in Outlook.

| 1 | If you're using Outlook for desktop, in the Cisco Webex group on the ribbon in Outlook, select Webex Preferences. ![Webex Preferences](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/430001-440000/433001-434000/433731.jpg) If you're using Outlook on the web, select New event \> Cisco Webex Scheduler ![Cisco Webex Scheduler](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/430001-440000/433001-434000/433680.jpg) \> Webex Preferences. |
| - | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2 | Select Change Webex site.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| 3 | Select or enter the Webex site URL that you want to use and select Next. ![Enter the Webex site URL to configure Webex scheduler](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/450001-460000/455001-456000/455005.jpg)                                                                                                                                                                                                                                                        |
| 4 | Select the default meeting type and select Save.                                                                                                                                                                                                                                                                                                                                                                                                                                                              |

[Remove the Webex Scheduler add-in](#id%5F96829)

If you installed the app yourself and you no longer want to schedule meetings using the Webex Scheduler, you can remove the app. If your administrator installed the app, contact your administrator to remove it.

| 1 | If you're using Outlook for desktop, select Get Add-ins in the Add-ins group in the Outlook ribbon. If you're using Outlook on the web, select More options![More options](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/440001-450000/447001-448000/447161.jpg) \> Get Add-ins.                    |
| - | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2 | Select My add-ins in the Microsoft 365 Add-ins window.                                                                                                                                                                                                                                                                             |
| 3 | Locate the Cisco Webex Scheduler and select ![More](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/430001-440000/433001-434000/433706.jpg) \> Remove. ![Webex Scheduler add-in](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/430001-440000/433001-434000/433707.jpg) |
