## Screen reader support

Desktop additionally supports the JAWS screen reading program for the elements listed below. 

For more information on the supported JAWS version, see the [Voluntary Product Accessibility Templates (VPAT) report](https://www.cisco.com/c/en/us/about/accessibility/voluntary-product-accessibility-templates.html#~collaboration) for Cisco Webex Contact Center Desktop.

## Access keyboard shortcuts

Use keyboard shortcuts to quickly access functions. Keyboard shortcuts are an another way to perform a certain action.

Before you begin

- You must be logged in to Desktop. See [Sign in to Webex Contact Center Agent Desktop](https://help.webex.com/en-us/article/n6lmci8/) for more information.
- Make sure that the focus is on Desktop.

| 1 | Click User Profile  \> Help \> Keyboard Shortcuts. The Keyboard Shortcuts List dialog box lists predefined and conflicting keyboard shortcuts.                                                                                                                                                                                                                                                                                                                                                                      |
| - | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2 | (Optional) To resize or move the Keyboard Shortcuts List dialog box, do the following: Hover the mouse pointer over the dialog box to drag it. Move the dialog box to the desired location by clicking and dragging it.Hover the mouse pointer over the boundary of the dialog box to re-size it. The pointer changes depending on where it is placed.The dialog box can't be re-sized beyond the minimum width and height of 480 x 320 pixels. This ensures that the content of the dialog box is always readable. |
