# Webex App | Set end-to-end encryption for meetings

Webex for Government supports end-to-end encrypted meetings in Webex App.

| 1 | [Sign in to your Webex site](https://globalpage-prod.webex.com/signin). |
| - | ----------------------------------------------------------------------- |
| 2 | Click Preferences \>  Scheduling.                                       |
| 3 | From the Meeting type drop-down list, select E2E Encryption + Identity. |
| 4 | Click Save.                                                             |
