# Enabling media streaming for specific queues

Media streaming facilitates tasks such as call transcription, summarization, suggested responses, and sentiment analysis. However, it does not work on the consult leg (for example, during consult or transfer calls).

**Prerequisites** 

- **Administrator access**—Ensure you have administrative privileges to access and modify flows in the Webex Contact Center.
- **Next Generation Media Platform** (**RTMS**)—Confirm you're a customer of the Next Generation Media Platform to access streaming functionalities.

Before you begin

_Flow Designer uses single sign-on (SSO) using Cisco Identity Service. If you're signed in to Control Hub or Webex Contact Center, you can access Flow Designer without signing in again. If not, the system prompts you to enter your SSO credentials._

Administrators can manually enable media streaming in the Flow Designer for specific queues by following these steps. However, if you wish to enable transcription for all calls, the queue-level conditional logic described below isn't required.

| 1  | Sign in to [Control Hub](https://admin.webex.com/login) using your administrator credentials.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| -- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2  | Navigate to Global Variables. Create a new global variable. Choose the variable type as boolean and set the default value as **False**. For more information about global variables, see [Manage global variables](https://help.webex.com/en-us/article/ngfdsbi/Manage-global-variables#task-template%5Fa5a9157e-62a8-4481-a8ed-22fa1eb4917a).![](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/480001-490000/489001-490000/489398.jpg)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| 3  | Go to Contact Center \> Customer Experience \> Flows. The **Flows** page appears.![](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/480001-490000/489001-490000/489341.jpg)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| 4  | Locate and open the call flow associated with the identified queues.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| 5  | In the main flow canvas, before you direct the call using the Queue Contact activity, set the global variable to True for queues that require transcription:![](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/480001-490000/489001-490000/489342.jpg) **Identify queues requiring transcription**: Determine which queues need transcription based on business requirements or call types. **Add a Set Variable Activity**: Before the **Queue Contact** activity, place a Set Variable activity. Change the value of the global variable to True for queues that need transcription. This ensures transcription is activated for the correct queues. Configure the Set Variable activity before the Queue Contact activity to ensure that your variable is set before the call is routed to an agent. This further ensures that the variable will be applied regardless of whether the call is answered right away or placed on hold. |
| 6  | In the event flow canvas, drag and drop the Condition activity after the AgentAnswered event. This activity evaluates if the global variable is True or False. True—For queues that require transcription.False—For queues that don’t require transcription.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| 7  | Drag and drop the Start Media Stream activity into the flow. ![](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/480001-490000/489001-490000/489343.jpg)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| 8  | Select the Start Media Stream activity to open its configuration settings, and set the following parameters: In the Activity Label field, enter a name for the activity.In the Activity Description field, enter a description for the activity.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| 9  | Connect the True path of the Conditionactivity to the Start Media Stream activity.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| 10 | Ensure that the flow logic remains intact, and that you have correctly positioned and configured the Condition and Start Media Stream activities.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| 11 | Click Save.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| 12 | Click Publish to deploy the updated flow and make the changes active and operational.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
