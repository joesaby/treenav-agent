# Generate migration license for devices using activation code flow onboarding

## Overview

Use activation codes from the control hub to activate your devices. You need a unique activation code for each device, to onboard or to migrate.

Only specific roles have permission to generate activation codes. For more information, see [Assign organization account roles in Control Hub](https://help.webex.com/en-us/fs78p5).

For W4G, the device migration license will have to be generated by a non-W4G account, for more information, refer [Migrate your phone to Webex Calling](https://help.webex.com/en-us/article/njojltfb/Migrate-your-Phone-and-Personal-Contacts-to-Webex-Calling--FedRAMP#concept-template%5F02c8296a-022e-4acd-9e79-2fa0b36f71be).

## Steps to onboard the device using activation codes

| 1 | To add a device through the activation code, For users, refer to [ Activation code-users](https://help.webex.com/en-us/article/ndb7w0db/Generate-an-activation-code-for-a-device#task-template%5Fecc55c51-1995-41e9-9f09-fd8ffaf7c5f6). For workspace, refer to [Activation Code-Workspace](https://help.webex.com/en-us/article/ndb7w0db/Generate-an-activation-code-for-a-device#task%5F28292F51CC004B0DA2461A37EFCC1F38). |
| - | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2 | After the activation code generation, share the code or enter the code when the device prompts.![](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/480001-490000/486001-487000/486791.png)                                                                                                                                                                                                      |
| 3 | Enter the migration license in the **Enter activation code** bar and then click **Continue**.                                                                                                                                                                                                                                                                                                                                |
| 4 | Once entered, the status changes to the **connection in progress**.![](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/480001-490000/486001-487000/486793.png) The reboot and restart of the devices starts and after that the device is successfully registered                                                                                                                                |
| 5 | Go to **Management** \> **Devices** to see the added devices.![](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/480001-490000/486001-487000/486809.png)                                                                                                                                                                                                                                        |

## Supported devices

The supported device models are listed below:

- Cisco IP Phone 6800 Series Multiplatform Phones (Audio phones—6821, 6841, 6851)
- Cisco IP Phone 7800 Series Multiplatform Phones (Audio phones—7811, 7821, 7841, 7861)
- Cisco IP Phone 8800 Series Multiplatform Phones (Audio phones—8811, 8841, 8851, 8861)
- Cisco IP Phone 8800 Series Multiplatform Phones (Video phones—8845, 8865)
- Cisco IP Conference Phone 7832 and 8832
- Cisco Desk Phone 9800 Series
