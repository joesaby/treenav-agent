# Webex App | Stop receiving incoming video in a meeting

You can stop or start receiving incoming videos while still being able to participate fully in the meeting and focus on audio communication.

- [Desktop](#task-template%5Fe3f31c5c-8b19-414f-9478-f3cda92648ed)
- [iPhone and iPad](#task-template%5F8bc12b83-c94d-42f5-a231-f9d93d0b1b1f)
- [Android](#task-template%5F74ff613f-369b-40c4-ad18-500510e02a23)

| 1 | During a meeting: Click Layout ![Layout](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/450001-460000/455001-456000/455202.jpg). Toggle on Stop incoming videos to stop receiving incoming videos. If you want to start receiving incoming videos, toggle off Stop incoming videos.                                                                                                                                                                                                                   |
| - | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2 | When you're not in a meeting: Click Settings ![](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/420001-430000/427001-428000/427579.jpg) on the [navigation sidebar](https://help.webex.com/nx3i8h5/) and select Meetings \> Layout. Check Stop incoming video when I join meetings. We save the value that you select in Settings ![](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/420001-430000/427001-428000/427579.jpg) so that it applies to all future meetings. |

| 1 | During the meeting, tap More options ![More Options button](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/450001-460000/450001-451000/450687.jpg) and then toggle on Stop incoming videos to stop receiving incoming videos. |
| - | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2 | If you want to start receiving incoming videos, toggle off Stop incoming videos.                                                                                                                                                                            |

| 1 | During the meeting, tap More options ![More Options button](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/450001-460000/450001-451000/450687.jpg) and then toggle off Receiving incoming videos to stop receiving incoming videos. |
| - | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2 | If you want to start receiving incoming videos, toggle on Receiving incoming videos.                                                                                                                                                                              |
