# Silence incoming call ringer (ignore calls) on 9800/8875

You can silence an incoming call when you are busy and don't want to be disturbed. The phone stops ringing; however, you get a visual alert and can answer the phone call using either the handset, speaker, or headset.

Silencing the ringer doesn't reject calls. If you’ve configured the line to redirect no-answer calls to your voicemail, you can check the voice messages later in the Recents list. 

On the phone with multiple lines, if you or your administrator enables the "Auto-collapse into line key" feature on the phones, the active call window is minimized to the line label itself. The inline call label can display the call session information, such as caller or callee name, number, call duration, call state, and call state relevant icons. In this situation, you can press the line key to open the full call window. This feature is available only on Cisco Desk Phone 9811, 9841, 9851, and 9861 registered to BroadWorks or Webex Calling.

| Do one of the following actions to silence an incoming call: Select Ignore. On the phone home screen, the incoming call that your ignored displays together with the incoming call icon ![the incoming call icon](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/480001-490000/488001-489000/488992.png) or ![the incoming call icon](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/470001-480000/479001-480000/479058.png) (depending on your phone model). The ring volume returns to normal with the next call. If you have multiple incoming calls at the same time, you can select Ignore all to silence the ringer for all the incoming calls. When you return to the incoming call or open the calls list (for multiple calls scenario), you can quickly find out the ignored incoming call(s) through the silenced icon ![Silenced icon](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/480001-490000/483001-484000/483292.png). The icon displays next to the ignored incoming call. Press the volume down key (-) ![the volume key](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/300001-400000/370001-380000/371001-372000/371854.jpg). The ring volume doesn't return to normal with the next call. You must manually volume up the ringer. |
