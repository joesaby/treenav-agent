# Bulk send activation emails in Control Hub

Sending activation emails this way sends out the emails again for all users who have the [Not Verified or Verified](https://help.webex.com/nikzbgy/) status. If users are on Cisco's suppression list, this process also clears them from the list to make sure that they receive the emails.

| 1 | Sign in to <https://admin.webex.com>.                                                                                                                                                                                                |
| - | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 2 | Click Users, then click Send invitations.                                                                                                                                                                                            |
| 3 | Click Send. The Tasks window opens automatically and shows your task progress. You can close the browser or this window and your task continues to run. To review the progress of your task, select Overview  \> Organization tasks. |
| 4 | If errors are recorded under Organization tasks \> Errors, select Export errors to CSV to see the errors in a CSV file.                                                                                                              |
