# Test your network

We recommend that you run the network test when you use the Desktop option to sign in to the Agent Desktop for the first time. Running the network test verifies that your network capabilities are suitable for the Desktop option. For more information, see the article [Use CScan to Test Webex Calling Network Quality](https://help.webex.com/en-us/article/y27bej/Use-CScan-to-Test-Webex-Calling-Network-Quality).

Before you begin

- You must be signed in to the Desktop. For more information, see [Sign In to the Agent Desktop](https://help.webex.com/en-us/article/n6lmci8/Sign-in-to-Agent-Desktop)
- If you are signing in to the Agent Desktop using the Desktop option outside your organization's network, use <https://cscan.webex.com/> to test the network before you sign in to the Agent Desktop.

| 1 | Click **User Profile** at the top-right corner of the Desktop.                        |
| - | ------------------------------------------------------------------------------------- |
| 2 | In the **Help** section, click **Test Your Network**.                                 |
| 3 | Choose the applicable options and click **Pick server**.                              |
| 4 | From the drop-down list, select **Adanced Diagnostic Test** and click **Start Test**. |
| 5 | Click **Continue** to **advanced test**.                                              |
| 6 | Click **Test Again** to test your network one more time.                              |
| 7 | Click **Test Another Server** to test your network on another server.                 |
| 8 | Click **Download this Report** to download the test report to your system.            |
