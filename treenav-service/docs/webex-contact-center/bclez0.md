# Change your dial number or extension

Before you begin

- Ensure you are signed in.
- Make sure there are no active tasks, monitoring sessions, interactions, or incoming task requests.

| 1 | Click User Profile \> Profile Settings.                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| - | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2 | In the Handle calls using drop-down list, choose one of the following options: Dial Number: Enter the ten-digit number. If it is an international number, check International Dialing Format. Find your country code from the drop-down list and enter the number. If it is a US number, enter in the standard US format, which is typically (+1) area code-phone number.Extension: Enter your extension number. If you don't see the dial number or extension options, contact your administrator. |
| 3 | (Optional) Check Don't show this again check box to enable auto sign-in for future sessions, skipping the Station Credentialsscreen on future sign-ins. Your station details are saved in your browser preferences regardless of whether this check box is selected.                                                                                                                                                                                                                                |
| 4 | Click Save and then Confirm.                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
