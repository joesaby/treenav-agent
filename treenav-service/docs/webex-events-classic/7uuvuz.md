# Set up your organization in Control Hub

If you became a Webex customer after May 9, 2023, Control Hub can guide you through setup tasks such as deploying the services you purchased, adding users and licenses, applying policies through [settings templates](https://help.webex.com/n5uf91x/), configuring your organization, setting up Meetings, Messaging, Calling, and Contact Center, and adding devices. 

You can also help your users get started with Webex by sharing a launch kit, visiting our [Adoption Resources Library](https://resources.webex.com/webex-essentials/onboard-and-implement), and joining the [Webex Community](https://community.cisco.com/t5/webex-administration/bd-p/collab-webex).

After you set up your environment, you can check to see how the adoption of Webex is going. Control Hub can also guide you through making your environment more secure.

[Check meetings adoption status and trends](#task-template%5Fa6afe486-675b-4534-a9b3-8c57a3b3078d)

After you set up your environment, check Webex Meetings adoption status among your users. Data trends start to appear after 60 days.

| 2 | Select a goal: Achieve standard-level security—Protect your users against identity theft and fraud by setting up [single sign-on](https://help.webex.com/nstvmyo/) (SSO), claiming users, and verifying your domain. This is the foundational level of security that every user can utilize. Achieve enhanced-level security—Provides a higher level of security with enhanced features to protect user access, and secure content and media streaming. Set up an idle timeout for Control Hub and the Webex web client, enforce authentication when users change their passwords, claim your verified domain, enable mandatory multi-factor authentication (MFA), and configure MFA. Achieve advanced-level security—Offers the highest level of security with premium features for content and media streaming security. You can also disable callback to certain countries, [deploy zero-trust meetings with end-to-end encryption and identity verification](https://help.webex.com/nedfu0h/), protect against viruses and malware, and set up [collaboration restrictions](https://help.webex.com/nlapmibb/), Hybrid Data Security (HDS), and Bring Your Own Key (BYOK). Protection against viruses and malware requires the [Control Hub Extended Security Pack](https://www.cisco.com/c/en/us/products/collateral/conferencing/webex-control-hub/datasheet-c78-742773.html). Collaboration restrictions, HDS and BYOK require [Pro Pack for Control Hub](https://help.webex.com/np3c1rm/). Secure user access refers to the measures implemented to safeguard a user's access to their account. It focuses on ensuring only authorized individuals have access, and it includes features like SSO, MFA, and domain verification. Secure content and media streaming refers to the set of security measures designed to protect the content and media that are transmitted during sessions, meetings, or webinars. These protections work to maintain the privacy and integrity of shared content, restrict unauthorized access, and provide a safe virtual collaboration environment. |
