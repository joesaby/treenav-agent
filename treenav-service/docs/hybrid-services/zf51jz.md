# See who's coming to a Webex Meeting

| 1 | Go to Meetings ![](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/420001-430000/420001-421000/420217.jpg) and select the meeting in the meetings list.                                                                                                                                 |
| - | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2 | Go to the People  list. ![](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/450001-460000/451001-452000/451623.jpg) The People  list shows everyone who's invited. Under each person's name, you can see if that person has accepted, declined, or not responded to the meeting invite. |
