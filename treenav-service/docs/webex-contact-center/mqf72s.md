# Manage teams in Webex Contact Center

## Create a team

A team is a group of people who support a specific group of functions.

Changes made to Teams and Desktop Layouts are linked through a bi-directional relationship. When a user modifies either a team or a desktop layout, updates are reflected in both areas and appear together in an entity. For example, this may result in audit logs displaying desktop layout changes when team settings are updated, and vice versa.

## Edit a team

You can change the team name and other settings. However, you can't change the team type from capacity based to agent based.

| 1 | Sign in to [Control Hub](https://admin.webex.com/).                       |
| - | ------------------------------------------------------------------------- |
| 2 | Select Services \> Contact Center.                                        |
| 3 | From the Contact Center navigation pane, select User Management \> Teams. |
| 4 | Select a team that you want to edit.                                      |
| 5 | Update the editable settings.                                             |
| 6 | Click Save.                                                               |

## Activate or deactivate a team

A team is active by default. You may want to activate a team that is deactivated previously. You can activate it again to add agents and associate it to a site.

| 1 | Sign in to [Control Hub](https://admin.webex.com/).                       |
| - | ------------------------------------------------------------------------- |
| 2 | Select Services \> Contact Center.                                        |
| 3 | From the Contact Center navigation pane, select User Management \> Teams. |
| 4 | Select a team that you want to activate or deactivate.                    |
| 5 | Toggle Activate or Inactive to activate or deactivate the the team.       |
| 6 | Click Save to save the change.                                            |

## Delete a team

You can only delete a team if that is in an inactive state.

| 1 | Sign in to [Control Hub](https://admin.webex.com/).                       |
| - | ------------------------------------------------------------------------- |
| 2 | Select Services \> Contact Center.                                        |
| 3 | From the Contact Center navigation pane, select User Management \> Teams. |
| 4 | Click the team that you want to delete from the list.                     |
| 5 | Click the Delete icon on the top right corner to delete the team.         |
