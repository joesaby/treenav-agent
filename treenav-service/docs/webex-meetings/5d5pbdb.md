# Delete users and licenses

If you're the account owner, you can't delete your user profile.

| 1 | From [Account Management](http://web.webex.com/admin), select the Users tab.                                                                                                                                                                                                                                                                         |
| - | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2 | To delete licenses, click![](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/450001-460000/458001-459000/458924.jpg)next to a blank row, or check Delete unassigned licenses to remove all unassigned licenses. To delete users, check Delete user next to the user's name, then click Continue \> Update subscription. |
