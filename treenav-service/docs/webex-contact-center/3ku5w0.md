# Resolve error issues

| 1 | Click the Error Details link in the error dialog box.                    |
| - | ------------------------------------------------------------------------ |
| 2 | Click Copy Tracking ID.                                                  |
| 3 | Share the copied tracking ID with your administrator to debug the issue. |

What to do next

If you experience problems with Desktop, you can send the logs to your administrator to investigate the issue, see [Download error reports](https://help.webex.com/en-us/article/neidf/Download-error-reports).
