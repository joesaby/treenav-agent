# Webex App | Access call recordings

This feature is only available if you are configured with Webex Call recording provider.

- [Desktop](#task-template%5F3cb7c4dc-140a-45c7-9e88-de203875a408)
- [iOS](#task-template%5F59c8f0c1-7950-4127-af28-c66b0639a95e)
- [Android](#task-template%5F0e3acce0-cf31-4985-a0ac-2f1a56896c44)

The recordings for the calls appear.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| 3 | Hover over any recording and choose what you want to do: Click ![](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/440001-450000/446001-447000/446491.jpg) to play the recording. The recording plays in the player.Click Audio ![](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/420001-430000/429001-430000/429940.jpg) or Video ![](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/430001-440000/438001-439000/438668.jpg) call to call the person.Click ![](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/410001-420000/417001-418000/417470.jpg) to send a message to the person.Click ![](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/450001-460000/458001-459000/458469.jpg) for more options, such as email or delete the recording. The message and email options appear only for the internal calls. |
