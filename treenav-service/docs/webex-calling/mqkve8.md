# Webex App | Release notes

We support the latest version of the Webex App and the versions that are available to administrators in Control Hub (see [Product update controls for Webex App desktop versions](https://help.webex.com/article/wlgw73/))

For the latest information about new features, check out [What’s New in Webex Suite](https://help.webex.com/8dmbcr/).

We report open and resolved customer-found bugs of severity 1 to 3\. When an update does not include customer-found bugs, there will not be a Resolved Bugs list shown for that update.

## Bug search tool

You can find details about listed bugs and search for other bugs impacting specific Webex App updates by using the [Cisco Bug Search Tool](https://tools.cisco.com/bugsearch/search). For more info on using the Bug Search, see [Bug Search Tool Help](https://www.cisco.com/c/en/us/support/web/tools/bst/bsthelp/index.html).
