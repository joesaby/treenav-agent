# Devices page in Control Hub

## Devices page

On the Devices page in Control Hub you can see a list of all devices your administrator role has access to. You can also make organization level changes, manage software, and manage individual devices.

### Device list

Devices list gives you an overview of all the devices in you organization. You can search and filter the list base on what you are interested in. You can also use [saved searches](https://help.webex.com/nts5p4p/) to quickly look up devices. The devices list is customizable.

**Customize the device list**

You can customize the device list to show the information that's important to you. Click on the cogwheel icon on the top of the list and select the information you want to see on the devices list. Click Reset to apply the changes.

The changes to the devices list are persistent and you'll see the same view next time you log in. You're changes are not visible to other Control Hub administrators.

You can choose from:

|             |                          |                     |
| ----------- | ------------------------ | ------------------- |
| All         | IP address               | Planned maintenance |
| Type        | Serial number            | Location            |
| Product     | Primary SIP address      | Last seen online    |
| Status      | Software Lifecycle       | Date onboarded      |
| Platform    | Network connectivity     | Tags                |
| Belongs to  | Software upgrade channel | SIP addresses       |
| MAC address | Calling                  | License type        |

### Bulk configure devices

You can select several devices from the list to apply changes to them in bulk. Select the devices you wish to configure and click Edit. This opens a side panel which gives you access to:

- View the device types you've selected.
- Select an action for all devices selected.
  - Export device information to CSV.
  - Delete the selected devices from Control Hub.
- Configurations
  - [Edit all configurations](https://help.webex.com/n5pqqcm/)
  - [Apply configurations templates](https://help.webex.com/n5pqqcm/#Cisco%5FReference.dita%5F32fda655-3543-41c1-a1c1-b9df163c7cf4)
  - [Edit digital signage](https://help.webex.com/nmd8log/)
  - [Edit Room Navigator persistent web app](https://help.webex.com/ohq3u6/)
- Edit tags
- Alerts
  - [Create new alerts](https://help.webex.com/nvsge9y/)
  - [Edit planned maintenance](https://help.webex.com/p5eszb/)

### Templates

Using [configuration templates](https://help.webex.com/n5pqqcm/#Cisco%5FReference.dita%5F32fda655-3543-41c1-a1c1-b9df163c7cf4) saves you time on configuring devices. All the templates you've created are available on Control Hub and you can apply, edit, and copy them later on. 

### XoD devices (Expert on Demand)

[Expert on Demand](https://help.webex.com/5wiovh/) aims to facilitate real-time advice, guidance, and assistance from professionals who possess specialized knowledge and skills. The solution is designed to facilitate knowledge sharing and problem-solving, enabling individuals or organizations to access expertise remotely without the need for a physical presence. 

### Settings

In the Settings tab you can enable configurations that can be applied to all of the devices. It is always possible to disable these for individual devices:

- Enable third-party meetings: [Microsoft Teams](https://help.webex.com/nsx4cpe/), [Google Meet](https://help.webex.com/egg1su/), [Zoom meetings](https://help.webex.com/zai3j4/)
- [Remote access](https://help.webex.com/gge81eb/) enables admins to manage devices remotely for enhanced support.
- [Device screen lock](https://help.webex.com/7y056e/) enables users to lock and unlock their devices with a PIN set on the device.
- [ThousandEyes](https://help.webex.com/gg3kd3/) solution provides enhanced troubleshooting and end-to-end experience monitoring.
- [Device discovery](https://help.webex.com/nz9iowf/) lets users find nearby Webex devices for sharing content.
- [Webex Assistant for devices](https://help.webex.com/nljt9yc/) lets users use their voice to interact with devices.
- [Branding](https://help.webex.com/rcxqacb/) lets you add logo and brand image on the device screen and touch controller.
- [Custom message](https://help.webex.com/nv1d9mw/) adds a short text string on the bottom left corner of the screen.
- Allow management of [Webex Edge for Devices](https://help.webex.com/cy2l2z/) linked device through Control Hub.
- Allow management of [Macros](https://help.webex.com/gj962f/) through Control Hub
- Device power consumption and carbon emissions that shows you the current CO2e emissions rate for your power supply profile.

### Software

In the software tab you can view the applied software channels and get information on the supported software versions. You can also configure advanced software maintenance from this tab. Read more about [RoomOS software upgrades](https://help.webex.com/idba5c/).

## Device details page

The device details page in Control Hub provides you with a centralized overview and management interface for each device. You can monitor device health, apply configurations, manage alerts, and access troubleshooting tools. The page also maintains a history of changes and supports lifecycle management, guiding you through key milestones from deployment to end-of-life, ensuring proactive and efficient device oversight.

### Actions

Click on the Actions button and select:

- [Reboot the device](https://help.webex.com/nx3uj0eb/)
- [Run xCommands](https://help.webex.com/9lk0bf/)
- Report a problem
- Delete the device from Control Hub

### Overview

The Overview section gives you detailed information on the device and the option to apply configurations, macros and more on the individual device.

- View details:
  - Network connectivity
  - IP address
  - MAC address
  - Serial number
  - SIP address
  - Lines
- [Change the device's software channel or provider](https://help.webex.com/idba5c/#sx10%5Ft%5Fsw%5Fchannel%5Fsingle%5Fworkspace)
- [Add alerts](https://help.webex.com/nvsge9y/) for the device
- [Planned maintenance](https://help.webex.com/p5eszb/)
- Apply tags to make it easier to filter the Devices list
- View issues and information with [smart diagnostics](https://help.webex.com/nb5qprp/)
- Find information on the connected peripherals
- Configure the device:
  - [Change configurations](https://help.webex.com/n5pqqcm/)
  - [Apply configurations templates](https://help.webex.com/n5pqqcm/#Cisco%5FReference.dita%5F32fda655-3543-41c1-a1c1-b9df163c7cf4)
  - [Apply digital signage](https://help.webex.com/nmd8log/)
  - [Set Room Navigator persistent web app](https://help.webex.com/ohq3u6/)
  - [Apply macros](https://help.webex.com/gj962f/)
- Access support and troubleshooting:
  - [Manage device logs](https://help.webex.com/np5qxxz/)
  - [Remote access to troubleshoot the device or meeting room](https://help.webex.com/gge81eb/)
  - [Local device controls](https://help.webex.com/n5pqqcm/#task%5Fi1d%5Fg55%5Fcz)
  - [Contact Cisco support](https://help.webex.com/n2ajs3o/)

### History

[Device history](https://help.webex.com/jhkg7ab/) allows you to quickly check what has happened on the device. Details on changes to configurations, macros, web apps, and software versions help you when you want to see what has been changed and when you have to troubleshoot a device. 

### Lifecycle management

Control Hub now provides [lifecycle management](https://help.webex.com/n9qmylfb/) for RoomOS devices, ensuring that you are informed about every step in the device's lifecycle from the end-of-sale notice to end-of-life. Lifecycle management offers suggested actions and resources at each relevant milestone, helping you to proactively manage and plan for device refreshes.
