# Resend an invitation email from Control Hub

- Invitees will continue to receive reminder emails until they sign into Webex App for the first time.
- Reminder emails are not currently available for Webex Meetings users.

| 1 | [Sign in to Control Hub](https://admin.webex.com/).                                                                                                                                                                                  |
| - | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 2 | Go to Users.                                                                                                                                                                                                                         |
| 3 | Select a user with the status Invite Pending, then select Actions \> ![More options icon](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/410001-420000/417001-418000/417370.jpg) \> Resend Invitation. |

Want to see how it's done? Watch this [video demonstration](https://youtu.be/lhKlZwJDuRo) on how to resend an invitation email from Control Hub.
