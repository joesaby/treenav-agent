# Manual closed captioning with communication access real-time translation (CART)

Customize your experience with adjustable font sizes, background colors, and reposition the caption box for enhanced accessibility and inclusivity in every meeting. To send closed captions to a Webex meeting, third-party (CART) closed caption software systems can send Https POST requests to the Webex CART API URL, with caption text. Only the meeting host on desktop platforms can get the caption link to pass to third-party software. Currently, hosts on mobile and desk devices can't access the caption settings, and can only see the manual captions when they appear in the meeting.

Currently, support is only available for line-by-line posted transcripts with third-party closed caption providers.

CART support is available on [Webex Meetings](https://help.webex.com/nqx2ohdb/), and with limited availability on the [Webex Suite meeting platform](https://help.webex.com/m61d8eb/).

If you prefer, [show automated captions](https://help.webex.com/lzi8h2/) or [turn on manual captioning and assign a captioner](https://help.webex.com/n366dqe/) to add captions to your meeting.

## For Hosts

Using the host controls on desktop, hosts can turn on manual captioning, copy the caption link and provide the link to the manual captioning service, and set the spoken and caption language.

Setting up manual captioning isn’t available for hosts using a mobile or Cisco Desk Series device.

| 1 | To show the Captions settings in a meeting, click the arrow beside the Show closed captions ![Show closed captions](https://cisco-api.ingeniuxondemand.com/DITA/content/en/us/td/i/400001-500000/440001-450000/442001-443000/442579.jpg) button.                                                                                                                                                                                                                                                      |
| - | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2 | In Host controls, toggle on Allow manual captioning.                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| 3 | Click Copy the caption link. This copies the manual API link to your clipboard. Provide this link to the manual captioning service. Please note the following API information: **Https method**—POST**Https Request Header**—Content type: text/plain.**Request body**—Plain text of closed captions. Please note the following API response status codes: **200**—The request is completed successfully.**400**—The request is invalid or can't be otherwise served.**403**—CART API URL is invalid. |

## For Attendees

As an attendee on a desktop, mobile, or desk device, you can only see manual captions if they are turned on by the host. You can choose to show or hide the closed captions.
